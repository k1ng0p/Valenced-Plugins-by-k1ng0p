# Valenced Plugins

**A collection of plugins by [k1ng0p](https://github.com/k1ng0p).**

Things I've built, features I've wanted, and plugins I've brought over to Valenced.

## Installation

Add this repository through **Settings → General → Plugins → Add Repository**.

```text
https://k1ng0p.github.io/Valenced-Plugins-by-k1ng0p/
```

## What's Inside

### ✦ Original

Plugins developed for this repository.

| Plugin | About |
|:--|:--|
| **Platform Spoof** | Spoofs your Discord gateway platform so others see a different client icon (Desktop, Web, VR, Console) on your profile. |
| **LastOnlineTracker** | Shows "Active X ago" under usernames in the member list once they go offline. |
| **Instant Actions** | Skips confirmation prompts for destructive actions - deleting messages, embeds, channels, leaving servers and groups. |
| **Plugin Browser** | Browse third-party repositories, see what they offer, and add them to Valenced. |
| **Junk Cleanup** | Hides useless Discord UI: Nitro and quest upsells, extra message menu rows, settings sections, server header buttons, voice call clutter and profile cosmetics. |
| **Watchlist** | Shows toasts when your friends or tracked users change status, start typing, or send a message. |
| **Profile Replies** | Reply or react to a friend's custom status or bio straight from their profile. |
