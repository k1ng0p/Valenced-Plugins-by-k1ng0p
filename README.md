# k1ng0p Valenced Plugins

Valenced plugin repository.

## Install

In Revenge: **Settings → General → Plugins → Add repository**, then paste:

```
https://k1ng0p.github.io/Valenced-Plugins-by-k1ng0p/
```

## Plugins

### Original

| Plugin | Description | Source |
|---|---|---|
| **Platform Spoof** | Spoofs your Discord gateway platform so others see a different client icon (Desktop, Web, VR, Console) on your profile. | Written by [k1ng0p](https://github.com/k1ng0p) for Valanced |
| **LastOnlineTracker** | Shows "Active X ago" under usernames in the member list once they go offline. | Written by [k1ng0p](https://github.com/k1ng0p) for Valanced |
| **Instant Actions** | Skips confirmation prompts for destructive actions - deleting messages, embeds, channels, leaving servers and groups.| Written by [k1ng0p](https://github.com/k1ng0p) for Valanced |
| **Plugin Browser** | Browse third-party repositories, see what they offer, and add them to Valanced.| Written by [k1ng0p](https://github.com/k1ng0p) for Valanced |
| **Junk Cleanup** | Hides useless Discord UI: Nitro and quest upsells, extra message menu rows, settings sections, server header buttons, voice call clutter and profile cosmetics. | Written by [k1ng0p](https://github.com/k1ng0p) for Valanced |
| **Watchlist** | Shows toasts when your friends or tracked users change status, start typing, or send a message.| Written by [k1ng0p](https://github.com/k1ng0p) for Valanced |
| **Status Reply** | Reply to friends' custom statuses straight from their profile, just like the desktop app.| Written by [k1ng0p](https://github.com/k1ng0p) for Valanced |
